# Third-party assets

The PNGs in this folder are from Kenney's **RTS Medieval** environment pack, Retina edition:

- Source mirror: https://github.com/shorepine/kenney/tree/main/2d/RTS%20Medieval/Retina/Environment
- Original filenames: `medievalEnvironment_01.png`, `02.png`, `03.png`, `05.png`, `09.png`, `12.png`, `19.png`, and `20.png`.
- License: CC0, as stated in the source repository README. Kenney requests credit as a courtesy but does not require it.

The derived `public/assets/world-map/textures/medieval-forest.png` brush combines these tree, bush, rock, and log sprites with AniBW's forest-group artwork. The files remain included here so the source artwork is identifiable and reusable.
